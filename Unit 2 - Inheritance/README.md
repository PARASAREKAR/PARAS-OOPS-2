## Overview
This folder contains all programs for Unit 2, exploring code reuse and extensibility through inheritance in C++. Topics include single, multilevel, multiple, hierarchical, and hybrid inheritance, constructor invocation order, visibility modes (public, protected, private), virtual base classes, composition, and friend functions.
